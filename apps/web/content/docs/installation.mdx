## Windows

Via [Microsoft Store](https://apps.microsoft.com/detail/9PG711NS9JVS) or
winget, no admin rights needed:

```powershell
winget install --id 9PG711NS9JVS --source msstore
```

To grab the `.msi` by hand instead, it's on the
[latest release](https://gitlab.com/viincnt/transfert/-/releases/permalink/latest)
page.

Either way you'll need:

- Windows 10 (1809+) or Windows 11, x64
- the WebView2 Runtime — already on Windows 11 and most up-to-date Windows 10
  machines; the installer pulls it automatically if it's missing

## macOS / Linux

Not packaged yet. macOS support is in progress — the app icon and `.icns`
bundle asset already exist in the repo, but no macOS build target is wired up
yet. If you want to try it anyway, see [Building from source](/docs/building-from-source).

## Updating

There's no in-app updater. A new version means a new installer — grab it
again from the Microsoft Store (auto-updates there) or the latest release
page for the `.msi`.
