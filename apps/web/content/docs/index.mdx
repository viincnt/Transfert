**Transfert** is a local-first file toolbox: conversion, compression and cleanup
tools that run entirely on your machine. Nothing is uploaded anywhere to get a
file converted — no server round-trip, no account, no telemetry. If your
computer can already do the job, Transfert just gives it a decent interface
for doing it.

## How it works

Every conversion decodes, re-encodes and then **verifies its own output**
before handing it back:

- writes get re-read and re-hashed
- encodes get re-decoded and compared against the source

A corrupted or truncated result is caught and discarded instead of silently
landing in your folder.

## Platform

Transfert currently ships for **Windows** (10 1809+ or 11, x64). macOS support
is in progress — the app icon and `.icns` bundle asset already exist, but no
macOS build target is wired up yet. Linux isn't packaged either.
